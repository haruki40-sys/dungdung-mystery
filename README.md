# CASE 001 · 달빛 악보 실종사건

비 내리는 산속 음악회장에서 사라진 악보 한 장을 추적하는 선택형 웹 추리게임입니다.

## 플레이 방법

1. 사건 브리핑을 확인합니다.
2. 현장을 조사하고 인물을 심문해 단서를 모읍니다.
3. 탐정수첩과 사건 시간표를 참고해 최종 결론을 제출합니다.

진행 기록은 현재 브라우저에 자동 저장됩니다. 처음부터 다시 시작하려면 화면 상단의 `처음부터`를 선택하세요.

## 실행 환경

- 최신 PC·모바일 브라우저
- 별도 설치나 로그인 불필요
- 정적 HTML·CSS·JavaScript로 실행

## 버전

`Bright Moonlight prototype v0.9`

## 기술 안내

이 게임은 브라우저에서 실행되는 정적 웹게임입니다. 게임 진행과 판정에 필요한 코드가 이용자의 브라우저로 전달되므로 개발자 도구를 통해 내부 로직을 확인할 수 있습니다.
